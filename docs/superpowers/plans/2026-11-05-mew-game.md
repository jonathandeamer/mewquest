# Mew Garden Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Deliver the approved safe, side-scrolling cat platformer.
**Architecture:** Dependency-free static Canvas game with a separately testable fixed-step simulation.
**Tech Stack:** HTML/CSS/JavaScript, Node test runner.
**Spec:** docs/superpowers/specs/2026-11-05-mew-garden-design.md

## Global Constraints
No violence or physical harm. Ginger Mew reaches white-skinned Jenn with brown ponytail. Gradual difficulty, checkpoints, mobile controls.

## Review Focus
- Lost keyboard focus must clear inputs and pause.
- Small screens must retain accessible controls.
- Fast dash must not tunnel through obstacles.
- Checkpoint return must preserve yarn and reset velocity.
- Replay must reset progress and collectibles.

### Task 1: Simulation
Files: dist/engine.mjs, tests/engine.test.mjs.
Interfaces: createGame(), step(game,input,dt), reset(game), returnToCheckpoint(game).
- [ ] Write and run failing tests for jump, dash limits/refill, safe reset, pause, replay, obstacles, patrol, collectibles, win, and route reachability.
- [ ] Implement fixed-step collision simulation and level data.
- [ ] Run node --test and commit.

### Task 2: Browser experience
